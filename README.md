VK Маруся — SPA для поиска и избранного
React / TypeScript приложение для поиска фильмов, просмотра деталей и управления избранным.

🚀 Основной функционал
Главная: случайный фильм + топ-10 по IMDb

Жанры: каталог с переходом к фильмам

Фильмы по жанру: пагинация (5–15 фильмов), адаптивная сетка

Страница фильма: детали, трейлер, кнопка в избранное

Личный кабинет: данные пользователя + избранные фильмы

Поиск: мгновенный, с дебаунсом (5 результатов)

Авторизация / регистрация: валидация, сессия в localStorage

🛠️ Стек
React, TypeScript, React Router

Redux Toolkit

SCSS (модули, BEM)

Axios

📦 Запуск
bash
npm install
npm start
